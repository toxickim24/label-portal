## 📝 Documentation Guidelines

### For Contributors

When adding new features or making significant changes:

1. **Update PROJECT_OVERVIEW.md**
   - Add new features to the "Current Features" section
   - Update architecture diagrams if structure changes
   - Document any new technical decisions

2. **Update PHASES.md**
   - Check off completed tasks
   - Add new planned features if scope expands
   - Update phase status and completion dates

3. **Update SETUP.md**
   - Add any new installation steps
   - Document new dependencies
   - Update configuration examples
   - Add troubleshooting for new issues

### Documentation Standards

- Use clear, concise language
- Include code examples where helpful
- Keep table of contents updated
- Use consistent markdown formatting
- Date all significant updates
- Include screenshots for UI changes (store in `/docs/images/`)
